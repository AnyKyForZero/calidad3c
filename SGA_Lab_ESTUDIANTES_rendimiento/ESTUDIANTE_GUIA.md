# Guia del estudiante
Objetivo: evaluar el SGA y gestionar defectos con evidencia.

Flujo: requisitos -> diseño de pruebas -> ejecución -> evidencia -> reporte -> corrección -> confirmación -> regresión.

Aplicar: unitarias, integración, sistema, confirmación, regresión, carga, estrés, capacidad, compatibilidad, UX, accesibilidad, tolerancia a fallos, seguridad, mantenibilidad y portabilidad.

Entregables: plan de pruebas, trazabilidad, casos, evidencias, defectos, correcciones, confirmación, regresión e informe final.
