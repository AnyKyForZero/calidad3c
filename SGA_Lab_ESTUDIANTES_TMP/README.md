# SGA - Laboratorio Calidad del Software II
Aplicacion web Flask + SQLite para practicar pruebas funcionales y no funcionales.

## Ejecutar
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python run.py
Abrir http://127.0.0.1:5000
